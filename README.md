# Академия новогоднего волшебства

Праздничный квест для трёх человек за одним ноутбуком. Сервер и база данных не нужны: прогресс хранится в `localStorage`.

```bash
npm install
npm run dev
```

Сборка для показа без режима разработки:

```bash
npm run build
npm run preview
```

Ответы и загадка допуска меняются в:

- `src/data/exams.ts` — восемь экзаменов
- `src/data/specialActivity.ts` — поиск допуска перед экзаменом 8
- `src/data/wordBank.ts` — слова для кафедры словесности

Панель организатора: `Ctrl + Shift + D`.

Рисунки персонажей и фоны можно положить в `public/assets/` под именами из `src/data/assets.ts`. Пока файла нет, приложение показывает запасной рисунок и не запрашивает битую картинку. После добавления файла перезапустите `npm run dev`.

Директор на экране приветствия ждёт прозрачный файл `public/assets/characters/director.webp`: оригинальный пожилой волшебник в красной шубе, с белой бородой и очками. Это не копия персонажа из фильма. Пока файла нет, на его месте мягкая праздничная заглушка.

Бумажные письма о зачислении печатаются отдельно и уже содержат речь директора. На сайте этой речи нет. QR-код на письме должен вести на публичный адрес сайта после выкладки, с `https://`, а не на `localhost`. Когда адрес будет известен, сгенерируйте QR по этой ссылке и вставьте его в макет письма. Код для локальной разработки в письмо не кладите.
